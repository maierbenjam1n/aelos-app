# Aelos pitch deck

Open `index.html` in Chrome or Chromium and press **F** for full screen.

The static, 13-page PDF version is [`aelos-pitch.pdf`](aelos-pitch.pdf).

- **← / →, Space or Enter:** navigate. On the instrument-price slide, Enter reveals the two price points in sequence before advancing.
- **N:** toggle speaker notes.
- **F:** toggle full screen.
- Click the right side of a slide to advance; the left side goes back.
- Add `?slide=3&step=2` to the URL to open a specific slide state while reviewing.

This is a browser-based deck so the staged price reveal works during the pitch. Slide changes are direct cuts. It uses the bundled Aelos fonts and instrument photographs. The QR code opens the public GitHub repository README. The insurer view is explicitly a concept view; the other app views are visual mockups based on the current demo flows.

Slides 11–13 from the supplied outline cover competitors and are intentionally kept out of the pitch. The corresponding internal notes live in [`docs/presentation-business.md`](../docs/presentation-business.md).
